Physical Cluster & Failure Domain Topology

Worker nodes (grouped by zone label when present) and the pods each one hosts. Faded, dashed pods are not ready; free capacity is allocatable minus pod requests.

ℹ️ What am I looking at?
  • Each box is a worker node (a machine). Each chip is a pod (one running copy of a service).
  • Kubernetes decides which node each pod runs on. This map is read from the cluster, not from the YAML.
  • Click a node to simulate its failure: services whose every ready copy is on that node turn red. Those services would have 0 ready replicas.
👆 Click a node below to see what happens if it fails.

Replica Concentration Distribution

Workload spreading across host failure domains

Replica concentration = largest share of a service's ready replicas on one node. Red = concentrated: all ready replicas on one node, so that node's failure leaves the service with 0 ready replicas.
